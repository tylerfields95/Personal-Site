#UI #Feature 

The blog Editor should be a new page in the app which allows for the management of blog objects. The user will be able to set up a blog with header information and various body sections. each section is configurable.

Types of section possible right now

* markdown renderer 
* images

For now the user can enter markdown formatted text with accompanying images. in each section of markdown, images can be positioned in any or all of the following locations: left, right, top, or bottom.

The goal is to allow the user to configure the blog in whatever way feels right in the moment for the piece. in this type of editor, its possible to set up a complex article like structure with very intentionally formatting. 



So, the editor should be represented as a form which allows the management of a blog object. containing a list of blog body objects. 

so, the form should let them fill out the top level information for the blog such as the title, sub title, author, date, etc 

once the user has filled in the header information of the blog, they will proceed by adding blank body sections which they will configure by adding markdown and images. 

The user will be able to see a preview of their blog.
