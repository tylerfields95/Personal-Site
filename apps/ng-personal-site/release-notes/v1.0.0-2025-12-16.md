# Release Notes - v1.0.0
**Release Date:** December 16, 2025
**Initial Public Release**
**Deployment:** AWS S3 + CloudFront
**Live at:** https://tylerfields.me

---

## Overview

First production release of Tyler Fields' personal portfolio website. Built as a modern single-page application using Angular 19 with standalone components, featuring a custom theming system, responsive design, and markdown-based content rendering.

---

## Core Features

### Application Architecture
- **Framework**: Angular 19 (standalone components, no NgModules)
- **State Management**: Angular Signals for reactive state
- **Routing**: Angular Router with lazy-loaded routes
- **Styling**: TailwindCSS v4 with custom theme system
- **Build Tool**: Vite-based Angular build system
- **Package Manager**: pnpm with workspace configuration

### Page Routes
- **Home Page** (`/`) - Welcome/introduction content with biography
- **Second Page** (`/second`) - Additional blog-style content page
- Expandable route system ready for future pages (projects, blog, about, contact)

## Theme System

### Color Architecture
- **5-Tier Color System**:
  - Primary (base layer)
  - Secondary (elevated surfaces)
  - Tertiary (borders, subtle elements)
  - Quaternary (scrollbar thumbs, subtle accents)
  - Quinary (available for future use)

- **Text Colors**:
  - Primary text (high contrast, main content)
  - Secondary text (supporting info, metadata)

- **Accent Colors**:
  - Accent: `rgb(107, 26, 116)` (deep purple)
  - Accent muted: `rgb(168, 72, 178)` (lighter purple)
  - Accent inverted: `rgb(255, 255, 255)` (white)

### Dark Theme (Default)
- Primary: zinc.900 `rgb(24, 24, 27)` - darkest base
- Secondary: zinc.800 `rgb(39, 39, 42)` - elevated content
- Tertiary: zinc.700 `rgb(63, 63, 70)` - borders/separators
- Quaternary: zinc.600 `rgb(82, 82, 91)` - scrollbar thumbs
- Quinary: zinc.500 `rgb(113, 113, 122)` - unused
- Primary text: zinc.100 `rgb(244, 244, 245)` - near white
- Secondary text: zinc.300 `rgb(209, 213, 219)` - light gray

### Light Theme
- Primary: `rgb(249, 249, 249)` - subtle gray base
- Secondary: `white` - elevated content
- Tertiary: `rgb(229, 229, 229)` - borders/separators
- Quaternary: `rgb(212, 212, 212)` - scrollbar thumbs
- Quinary: `rgb(163, 163, 163)` - unused
- Primary text: `black` - high contrast
- Secondary text: zinc.700 `rgb(63, 63, 70)` - dark gray

### Theme Features
- **Persistence**: Theme preference saved to browser localStorage
- **Smooth Transitions**: 300ms ease-in-out for all color changes
- **Synchronized Animation**: All components transition colors together
- **Toggle Control**: Sidebar-based theme switcher with visual feedback
- **Default**: Dark theme on first visit

## Services

### Theme Service
- Injectable singleton (`providedIn: 'root'`)
- Signal-based reactive state management
- localStorage integration for persistence
- Read-only public signal exposure
- Private mutable signal for internal state
- Methods:
  - `isDarkTheme()`: Returns current theme state (boolean)
  - `setTheme(value)`: Updates theme and persists to localStorage

### Viewport Service
- Injectable singleton
- Reactive viewport size tracking
- Signal-based width/height measurements
- Computed breakpoint helpers for responsive design
- Window resize event handling

## Responsive Design

### Breakpoints
- Mobile-first approach
- Tailwind default breakpoints:
  - sm: 640px
  - md: 768px
  - lg: 1024px
  - xl: 1280px
  - 2xl: 1536px

### Layout Behavior
- **Mobile**: Header navigation, collapsed sidebar
- **Tablet/Desktop**: Expanded sidebar, hidden header
- **Responsive text**: Scaled heading sizes based on viewport
- **Flexible images**: Sized proportionally to container

### Scrollbar Styling
- Custom scrollbar via tailwind-scrollbar plugin
- Themed thumb and track colors
- Rounded scrollbar thumb
- Thin scrollbar width
- Pseudoelement strategy for consistent rendering

### Deployment Process
1. Build: `pnpm build`
2. Sync to S3: `aws s3 sync` with `--delete` flag
3. CloudFront invalidation: `/*` wildcard path
4. Typical propagation: 1-5 minutes
